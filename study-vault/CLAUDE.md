# Study Vault 운영 규칙 (Claude용)

주인: 경영학과 학생. 2026-2학기 과목 + 금융학회(엑셀 재무모델링, 증권리포트) 활동을 기록한다.
모든 노트는 **한국어**, 초보자도 이해할 수 있는 쉬운 말로 쓴다.

## 폴더 = PARA
- `0-Inbox/` 미분류. 새 노트는 일단 여기. `import/`는 과거 대화 원본(커밋 금지).
- `1-Projects/` 끝이 있는 것. `2026-2/<과목>/`, `금융학회/재무모델링|증권리포트/<주제>/`
- `2-Areas/` 끝이 없는 영역: 금융학회-활동, 경영학-전공역량, 진로-금융권
- `3-Resources/` 재사용 지식: 재무-회계-개념, 엑셀-모델링, 리포트-작성법, 도서-논문-기사
- `4-Archive/` 끝난 것. **삭제 금지, 이동만.**

## 분류 판단 기준
1. 이번 학기 수업/학회 산출물에 직결 → Projects
2. 지속적 활동·역량·일정 → Areas
3. 여러 곳에서 재사용되는 개념·팁 → Resources (과목 노트에서는 `[[링크]]`만)
4. 종료된 학기·과목·리포트 → Archive (핵심 개념은 먼저 Resources로 추출)
- 재무관리·중급재무회계·학회는 개념이 겹친다. 공통 개념(현금흐름, 감가상각, 할인율 등)은 `3-Resources/재무-회계-개념/`에 **한 번만** 쓰고 링크한다.

## 노트 규칙
- 파일명: 강의노트 `weekNN-주제.md`, 개념 `개념명.md`, 그 외 `주제.md`. 템플릿은 `_templates/`.
- 프론트매터 필수: type(강의노트|개념|과제|Q&A|모델링|증권리포트), course/project, date, status(초안|검토완료), tags.
- 본문 순서: 한 줄 요약 → 핵심 개념 → 예시/코드/수식 → 헷갈렸던 점 → 관련 노트.
- 관련 노트는 `[[위키링크]]`로 연결. 새 노트를 만들면 관련 기존 노트에도 링크를 추가한다.
- 엑셀 모델링 노트는 파일 설명서: 모델 구조, 핵심 가정, 수식 로직, 검증 방법. xlsx는 같은 폴더에 두고 링크.
- 각 과목/프로젝트 폴더에는 `_index.md`(개요, 진도, 일정, 노트 목록)를 유지한다.

## 자동 재분류 규칙 (사용자가 따로 시키지 않아도)
세션 시작 시 / 주간 루틴에서:
1. `0-Inbox/`의 노트를 위 기준으로 알맞은 위치로 이동하고 프론트매터를 보정한다.
2. 최근 대화에서 배운 내용이 있으면 해당 노트에 반영하거나 새 노트를 만든다.
3. 각 `_index.md`의 노트 목록·진도를 갱신한다.
4. 끊어진 링크, 중복 개념 노트를 찾아 병합/연결한다 (삭제 대신 Archive).
5. 확신이 없는 분류는 옮기지 말고 `0-Inbox/분류-확인필요.md`에 질문으로 남긴다.
6. 변경 후 커밋 메시지에 이동/생성 요약을 적는다.

## 과거 대화 가져오기
`0-Inbox/import/`에 claude.ai 내보내기(conversations.json)를 넣으면: 대화별로 읽고 학습·학회 관련만 골라 요약 → 알맞은 위치에 노트 생성 → 링크. 무관한 대화는 건너뛴다. 원본은 커밋하지 않는다.
